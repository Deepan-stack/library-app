# Athenaeum — Library Management System (Runs Instantly)

## How to run
Just double-click **index.html** — it opens directly in your browser.
No installation, no server, no terminal commands needed.

(A Python/Streamlit version — app.py — is also included if you'd rather run it
as a Python web app: `pip install -r requirements.txt` then `streamlit run app.py`)

## What's inside
- Role switcher: Admin / Librarian / Student, each with its own sidebar
- Dashboard per role: KPI cards + weekly chart (Admin), overdue table (Librarian), borrowed books (Student)
- Catalog page: live search, category filter, add/edit/delete (Admin & Librarian),
  reserve-a-copy (Student) — all changes update instantly across the app
- Other sidebar items are placeholder pages for future build-out

## Files
- index.html        — the instant-run version (open this one)
- app.py             — Python/Streamlit version
- requirements.txt   — dependencies for the Python version
